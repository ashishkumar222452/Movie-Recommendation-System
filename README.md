# Movie Recommendation System

## 1. Project Overview

This project is a Machine Learning-based Movie Recommendation System that suggests similar movies based on content analysis and similarity measures.

## 2. Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## 3. Features

- Movie Recommendation
- Similarity Analysis
- Data Preprocessing
- Content-Based Filtering

## 4. How to Run

1. Install required libraries:

```bash
pip install pandas numpy scikit-learn
```

2. Open Jupyter Notebook.

3. Run the project notebook.
